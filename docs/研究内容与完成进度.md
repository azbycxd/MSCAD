# 研究内容与完成进度

本文档用于梳理当前课题的主要研究内容，以及每一部分目前的完成进度。整体课题围绕多变量时间序列异常检测展开，核心思路是在轻量级自编码器基础上，引入多尺度通道结构关系建模，从而同时利用数值重构误差和通道关系偏差进行异常检测。

## 1. 研究背景与问题定义

### 研究内容

本课题面向工业控制系统、航天器遥测和发动机退化等多变量时间序列场景。此类数据通常包含多个传感器通道，异常不仅可能表现为单个通道的数值突变，也可能表现为多个通道之间原有协同关系被破坏。

因此，本课题关注的问题是：

> 在仅使用正常数据训练的无监督异常检测场景下，如何同时利用数值重构误差和多通道结构关系变化，提高异常检测的稳定性、轻量性和可解释性。

## 2. 相关方法调研与基线选择

### 研究内容

1. AE：基础重构式自编码器；
2. LSTM-AE：基于循环神经网络的时序重构模型；

5. MTAD 类模型：结合重构和预测的深度时序异常检测模型；
6. CATCH 类模型：强调频域建模和通道融合的异常检测模型。

## 3. MSCAD 方法设计

### 研究内容

本课题设计 MSCAD 方法，在轻量级一维卷积自编码器基础上加入多尺度结构约束。方法主要包括：

1. 重构主干：使用一维卷积自编码器重构多变量时间序列窗口；
2. 重构损失：捕捉单通道数值偏移和局部形态异常；
3. 短期结构损失：关注窗口末尾短时间片段中的通道关系变化；
4. 长期结构损失：关注完整窗口中的整体通道协同关系；
5. 结构异常分数：比较原始窗口和重构窗口的通道关系矩阵差异；
6. 融合异常分数：融合 rec、short structure、long structure 三类分数。

### 已完成内容

1. 已完成结构项相关消融实验。
2. 已发现结构项不是越强越好，强结构约束可能影响重构主干学习。
3. 已初步形成“两阶段训练更合理”的解释：先进行重构预训练，再用弱结构约束微调。

### 当前结论

消融实验部分说明：

1. 结构信息有助于异常排序，但对最终 F1 的影响受阈值策略影响较大。
2. 短期结构和长期结构具有不同关注范围，可以作为互补信号。
3. corr 相比 cov 和 shrink_cov 更适合作为当前主结构度量。
